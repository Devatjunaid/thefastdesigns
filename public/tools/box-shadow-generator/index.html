About this css box shadow generator
Shadows create depth and hierarchy in flat interfaces. Subtle, large-blur shadows with low opacity look the most natural. The layered mode stacks four progressively larger shadows, a technique used by modern design systems to mimic how real light falls off.
Negative spread keeps shadows tucked under the element so they don’t look muddy, and inset shadows are useful for pressed buttons and input fields.


Worked example
For a subtle card, try a Y offset of 12px, 32px blur, −6px spread and 18% opacity. The negative spread keeps the shadow tucked under the card, so it reads as depth rather than a dark outline.


Tips and best practices
  • Real shadows fall downward: use a positive Y offset and little or no X offset.
  • Use the same light direction for every shadow in the interface so depth looks consistent.
  • Define 3–5 elevation levels (for cards, dropdowns, modals) and reuse them instead of creating new shadows.
  • Tint shadows with the background hue instead of pure black for a softer, more natural look.
  • Animating box-shadow repaints on every frame; for hover effects, animate the opacity of a pseudo-element that holds the shadow instead.

Frequently asked questions
What does each box-shadow value mean?
The order is offset-x, offset-y, blur radius, spread radius and color. Add “inset” at the start for an inner shadow.
How do I make a soft shadow?
Use a large blur (24–48px), small Y offset, slightly negative spread and low opacity (8–20%). Or enable layered mode.
