About this screen resolution checker

Screen resolution and viewport size are different things. The screen size is the whole display; the viewport is the part of the browser window where your page renders, which is what CSS media queries respond to. On high-density displays, CSS pixels are also different from physical pixels: a device pixel ratio (DPR) of 3 means each CSS pixel is drawn with a 3×3 block of physical pixels.

That’s why a phone with a 1179px-wide panel reports a 393px-wide screen to websites. Designers use the DPR to decide whether to export images at 2× or 3×.

Tips and best practices

  • Design breakpoints around your content, but test at common viewport widths like 360, 390, 768, 1280 and 1440px.
  • Export raster images at 2× for most modern screens; 3× rarely gives a visible gain for photos.
  • Use SVG for icons and logos so DPR never matters.
  • Include this report in bug tickets; many layout bugs only happen at a specific viewport size or zoom level.
  • Browser zoom changes the reported device pixel ratio and viewport size, so reset zoom before measuring.

Frequently asked questions

Why is my screen resolution smaller than my monitor’s specs?

Browsers report CSS pixels. With display scaling or a high-DPI screen, CSS pixels equal physical pixels divided by the device pixel ratio.

What is a device pixel ratio?

The number of physical pixels per CSS pixel. 2 means each CSS pixel uses a 2×2 grid of physical pixels.
