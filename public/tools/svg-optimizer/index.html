How to use the SVG Optimizer

  1. Upload an SVG file or paste SVG code.
  2. Choose the decimal precision for coordinates (2 is safe for most icons).
  3. Click Optimize and compare the original and optimized previews.
  4. Copy the code or download the optimized file.

About this svg optimizer

Design tools add a lot to exported SVGs: XML declarations, generator comments, editor namespaces (Inkscape, Sketch, Illustrator), metadata blocks, empty groups, unused IDs and coordinates with six or more decimal places. None of this affects how the graphic looks in a browser. Removing it often cuts icon files by 30–60%.

This optimizer works on the parsed SVG structure rather than with blind text replacement, and shows both versions side by side so you can confirm nothing changed. For build pipelines, SVGO is the standard command-line tool with many more optimisations.

Worked example

Exports from Inkscape and Illustrator often shrink by 20–70% once the XML declaration, generator comments, metadata blocks, editor attributes and six-decimal coordinates are removed.

Tips and best practices

  • Precision 1–2 is enough for icons displayed under 100px; use 3 for large illustrations or maps.
  • Keep <title> for meaningful standalone SVG images, because screen readers use it as the accessible name.
  • Convert text to outlines in your design tool before exporting if the font may not be available.
  • Inline small optimized SVG icons directly into HTML to save requests and allow CSS coloring with currentColor.
  • Always compare the previews; very low precision can distort small curves.

Frequently asked questions

Will optimizing change how my SVG looks?

It shouldn’t at precision 2 or higher. Compare the previews; if anything shifts, raise the precision.

Why are SVGs from Illustrator or Inkscape so large?

They include editor metadata, namespaces and very precise coordinates that browsers don’t need.
