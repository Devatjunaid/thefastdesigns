How to use the Mesh Gradient Generator
  1. Choose a base color and four accent colors, or click “Random colors”.
  2. Shuffle the positions until the blend looks right.
  3. Adjust the spread to make color areas larger or smaller.
  4. Copy the CSS or download a PNG in the size you need.


About this mesh gradient generator
True mesh gradients (like those in Illustrator) interpolate colors across a grid of points. CSS has no mesh gradient function, but stacking several radial gradients that fade to transparent over a base color produces a very similar soft, “aurora” look with no images at all.
The CSS version weighs a few hundred bytes and scales to any screen. The PNG export renders the same gradients on a canvas, which is useful for slides, social posts or desktop wallpapers.


Tips and best practices
  • Keep accent colors close in lightness for a calm blend; mix light and dark for drama.
  • Use a near-white base with pastel accents behind dark text to keep contrast high.
  • Large gradients can band on some screens; adding a subtle noise texture on top hides banding.
  • Put text on the calmest part of the gradient, or add a semi-transparent panel behind it.
  • Reuse brand colors from your palette so the background feels on-brand rather than random.

Frequently asked questions
Does CSS support mesh gradients?
Not directly. Layering several radial-gradient() backgrounds that fade to transparent creates a very similar effect, which is what this tool outputs.
Is the CSS version heavy for performance?
No. It is a few hundred bytes of CSS and renders on the GPU in all modern browsers.
