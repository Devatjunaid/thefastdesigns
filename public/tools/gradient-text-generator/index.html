How to use the Gradient Text Generator
  1. Type your heading text.

About this gradient text generator
Gradient text works by painting a gradient as the element’s background, clipping that background to the shape of the text with background-clip: text, and making the text fill transparent. The -webkit- prefixed properties are still needed for Safari and some Chromium versions, so the generated code includes both.


Worked example
A 90° gradient from #8a6d3b to #e0a96d on a 72px heading at weight 900 shows the effect clearly. At 16px the gradient is barely visible.


Tips and best practices
  • Use heavy weights (700–900) so there’s enough letter area to show the gradient.
  • Check contrast at both ends of the gradient against the background; the lightest color decides readability.
  • Reserve gradient text for one or two headlines per page so it keeps its impact.
  • Screen readers read the text normally, but text selection highlighting may look odd; that’s expected.
  • If the element spans multiple lines, add box-decoration-break: clone to repeat the gradient per line.

Frequently asked questions
Why is my gradient text invisible?
Usually the browser doesn’t support the unprefixed property. Include -webkit-background-clip: text and -webkit-text-fill-color: transparent, as this generator does.
Is gradient text bad for SEO?
No. The text is still real, selectable HTML text that search engines can read.
