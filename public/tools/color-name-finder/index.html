About this color name finder

CSS defines 148 named color keywords (including duplicate spellings like gray/grey and aqua/cyan). Names such as rebeccapurple, papayawhip and cornflowerblue come from the X11 color list, which explains their quirky choices.

Matching uses the CIELAB color space and the Delta E (CIE76) distance instead of raw RGB distance, because Lab is designed so that equal numeric distances look roughly equally different to the human eye. A ΔE under about 2.3 is often cited as a just-noticeable difference.

Tips and best practices

  • Use the closest name as a readable label in design tokens, for example “steelblue-ish primary”, even if you keep the exact HEX in code.
  • A ΔE above 10 means no CSS name is a good match; describe the color by hue and lightness instead.
  • Named colors are handy in quick prototypes and code demos because they are easy to read and remember.
  • Avoid relying on named colors for brand work: they are fixed values and rarely match a brand guide exactly.
  • Remember that gray, grey, darkgray and darkgrey exist, and that darkgray is actually lighter than gray.

Frequently asked questions

How many named colors does CSS have?

148 keywords, including duplicate spellings, which map to about 139 unique colors.

What is Delta E?

A measure of the visual difference between two colors in Lab color space. Lower is closer; under about 2 is barely noticeable.
