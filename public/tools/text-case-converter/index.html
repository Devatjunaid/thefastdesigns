About this text case converter

Title case capitalises the main words of a headline. Style guides disagree on details: AP style capitalises words of four letters or more, while Chicago lowercases all articles, coordinating conjunctions and prepositions regardless of length. This converter follows a common middle ground: the first and last words are always capitalised, short articles, conjunctions and prepositions are lowercased, and words with existing inner capitals or numbers (iPhone, CSS3, McDonald) are left alone.

Programming cases (camelCase, snake_case, kebab-case) are handy for naming CSS classes, design tokens, files and variables.

Tips and best practices

  • Use sentence case for UI labels and buttons; it reads faster and feels friendlier than title case.
  • Use kebab-case for CSS class names and file names that appear in URLs.
  • Design tokens are commonly written in kebab-case in CSS (--color-primary) and camelCase in JavaScript (colorPrimary).
  • Avoid long passages in ALL CAPS; uppercase text is slower to read. If you need caps for style, use CSS text-transform so screen readers get normal text.
  • Double-check brand names after converting: tools can’t know that “iOS” or “eBay” have special casing.

Frequently asked questions

What is the difference between title case and sentence case?

Title case capitalises most words in a heading; sentence case only capitalises the first word and proper nouns.

Which words stay lowercase in title case?

Short articles, conjunctions and prepositions such as a, an, the, and, but, of, in, on and to, unless they are the first or last word.
