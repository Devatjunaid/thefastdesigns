How to use the CSS Triangle Generator
  1. Click an arrow to choose the direction the triangle points.
  2. Set width, height and color.
  3. Copy the border-based CSS or the clip-path version.
  4. Position it with absolute positioning next to your tooltip or menu.


About this css triangle generator
The classic CSS triangle uses a zero-size element with thick borders. Where two borders meet, the browser draws a diagonal join, so making three sides transparent leaves a single colored triangle. It works in every browser ever made.
The clip-path version is easier to read and supports backgrounds and gradients, but borders and box-shadows get clipped with it.


Tips and best practices
  • For tooltip arrows, generate the triangle in a ::before or ::after pseudo-element instead of extra HTML.
  • To give an arrow a border, stack two triangles: a slightly larger one in the border color behind the fill.
  • Use the clip-path version if you need a gradient-filled triangle.
  • Keep arrows around 8–12px wide for tooltips; larger looks clumsy.
  • Use aria-hidden or pseudo-elements so decorative triangles aren’t announced by screen readers.

Frequently asked questions
How does the CSS border triangle work?
Borders meet at diagonal angles. With zero width and height, three transparent borders and one colored border form a triangle.
Which method should I use?
Borders for tiny tooltip arrows with maximum compatibility; clip-path when you need gradients or easier sizing.
