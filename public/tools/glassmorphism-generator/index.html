How to use the Glassmorphism Generator
  1. Increase the blur to frost the glass more.
  2. Adjust transparency and saturation to taste.
  3. Set the border opacity and corner radius.
  4. Copy the CSS and place the element over a colorful background.


About this glassmorphism generator
Glassmorphism uses a semi-transparent background combined with backdrop-filter: blur() so content behind the element appears frosted. It works best over vivid gradients or photos and with a subtle light border that mimics the edge of glass.
The generated code includes the -webkit- prefix for Safari. Keep text contrast in mind — add more opacity if text becomes hard to read.


Worked example
14px blur, 22% white and 160% saturation gives a light frosted card. If text on it becomes hard to read over bright areas, raise the white to 40–50% rather than adding more blur.


Tips and best practices
  • Glass needs something colorful behind it; on a plain background it just looks grey.
  • Increase opacity of the glass background if text sits on it, so contrast stays above 4.5:1.
  • backdrop-filter is GPU-intensive; avoid stacking many large blurred layers on low-end mobile devices.
  • A 1px light border at the top and left edges sells the glass effect more than a heavier blur.
  • Provide a solid fallback background with @supports not (backdrop-filter: blur(1px)) for older browsers.

Frequently asked questions
Is backdrop-filter supported in all browsers?
Yes, all current versions of Chrome, Edge, Firefox and Safari support it (Safari with the -webkit- prefix, which is included).
Why doesn’t my glass effect show?
The element needs something visible behind it and a background color that is partly transparent.
