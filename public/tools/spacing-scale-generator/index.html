How to use the Spacing Scale Generator
  1. Choose a base unit, usually 4px or 8px.
  2. Choose how the steps grow.
  3. Set the number of steps and a token prefix.
  4. Copy the CSS variables or JSON tokens.


About this spacing scale generator
The 8-point grid, popularised by Material Design and many product teams, sizes and spaces elements in multiples of 8px. Most common screen sizes divide evenly by 8, and halving and doubling stay on the grid. A 4px base gives finer control for dense interfaces and small components, which is why many systems use 4px steps for small values and 8px steps for larger ones.
The “practical” progression grows slowly at small sizes, where you need fine control for padding, and faster at large sizes, where you only need a few section-spacing values.


Tips and best practices
  • Use the smallest steps (4–12px) inside components and the larger ones (32–96px) between page sections.
  • Space related items closer together than unrelated ones; spacing communicates grouping.
  • Limit yourself to the tokens; one-off values like 13px or 27px are what make layouts look messy.
  • Set line heights to multiples of 4 so text aligns to the same rhythm as spacing.
  • Name tokens by step number or t-shirt size and never by value, so you can retune the scale later.

Frequently asked questions
What is the 8pt grid?
A system where all spacing and sizes are multiples of 8px, which keeps layouts consistent and scales cleanly across screen densities.
Should I use 4px or 8px?
Use 8px as the main rhythm and 4px for fine adjustments inside small components like icons, badges and inputs.
