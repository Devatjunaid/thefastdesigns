About this tints & shades generator
In color theory a tint is a color mixed with white, and a shade is a color mixed with black. Building a consistent scale from your brand color lets you create hover and active states, subtle backgrounds, borders and dark-mode variants that always feel on-brand.
This generator mixes colors in RGB space, which matches the way tools like Sass mix() work, so the output is predictable for developers.


Worked example
A 20% tint of #8A6D3B is #A18A62, and a 20% shade is #6E572F. Use a 90% tint as a soft badge background and a 40–50% shade of the same color for the badge text.


Tips and best practices
  • Use very light tints (90–95%) for hover backgrounds on list rows and table stripes.
  • Darker shades of a brand color often make better text colors than pure black because they feel warmer and more on-brand.
  • Mixing with white also reduces saturation; if a tint looks washed out, increase saturation in a color scale generator instead.
  • Name tokens by percentage (tint-80, shade-20) so the whole team understands how they were made.
  • Pair each tint with a shade of the same hue for badges: light background, dark text, same family.

Frequently asked questions
What is the difference between a tint and a shade?
A tint adds white to make a color lighter; a shade adds black to make it darker. A tone adds grey.
How do I use tints in UI design?
Light tints (80–95%) make great backgrounds and badges, mid tints work for borders, and shades are ideal for hover states and text on light backgrounds.
