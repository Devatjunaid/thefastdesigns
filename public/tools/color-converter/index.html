About this color converter

Designers and developers constantly switch between color formats: brand guidelines list HEX, CSS often uses RGB or HSL, and print shops ask for CMYK. This color converter removes the guesswork by translating a single color into all common notations at once.

HSL (hue, saturation, lightness) is great for building consistent themes in CSS, while HSV/HSB matches the color pickers in Photoshop and Figma. CMYK values are a mathematical conversion — for critical print work always confirm with your printer’s color profile.

Worked example

Paste #1A73E8 and you get rgb(26, 115, 232), hsl(214, 82%, 51%) and cmyk(89%, 50%, 0%, 9%). Lower the HSL lightness to 41% for a hover shade, or use the CMYK values as a starting point for a print proof.

Tips and best practices

  • Store brand colors as HEX in your style guide, but use HSL in CSS when you need to derive lighter or darker variants by changing only the lightness value.
  • Modern CSS accepts space-separated syntax like rgb(200 169 126 / 50%); both the comma and space formats produce the same color.
  • CMYK values from a formula are a starting point only. Ask your printer for the ICC profile they use (for example FOGRA39 or GRACoL) and convert in a design app for final artwork.
  • HSV/HSB values match the color pickers in Photoshop and Figma, which makes it easy to recreate a color you saw in a design file.
  • When a client sends a color as a name (“navy”, “teal”), convert it here first so everyone works from the same exact value.

Frequently asked questions

How do I convert HEX to RGB?

Paste the HEX code (for example #C8A97E) into the input. The RGB value appears instantly — rgb(200, 169, 126) — and you can copy it with one click.

Does it support transparency?

Yes. Enter an 8-digit HEX or an rgba()/hsla() value and the tool shows the alpha channel in RGBA and HEX8 formats.

Are CMYK values print-accurate?

They are a standard formula-based conversion. Real print output depends on paper and ICC profiles, so use them as a starting point.
