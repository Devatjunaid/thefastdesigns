About this css loader & spinner generator
CSS loaders animate only transform and opacity, the two properties browsers can animate on the compositor without re-layout, so they stay smooth even while the main thread is busy loading data. They also weigh a fraction of an animated GIF and stay sharp at any size.
The snippet includes role="status" and an aria-label so screen readers announce the loading state, plus a reduced-motion rule that slows the animation for users who request less motion.


Tips and best practices
  • Only show a spinner if loading takes longer than about 300ms; flashing loaders feel slower than no loader.
  • For waits over a few seconds, prefer a progress bar or skeleton screen that shows real progress.
  • Match the loader color to your accent color, but keep enough contrast against the background.
  • Center the loader in the area that is loading, not the whole page, so users know what is pending.
  • Keep the aria-label meaningful, e.g. “Loading search results”.
