Type Scale Generator

Choose a base size and a musical ratio to generate a consistent set of font sizes for body text and headings, with a live preview and CSS tokens.

100% freeNo sign-upWorks offlinePrivate — runs in your browser


How to use the Type Scale Generator
  1. Enter your base body font size (16px is the browser default).
  2. Choose a scale ratio — smaller ratios suit dense UIs, larger ones suit editorial sites.
  3. Set how many steps up and down you need.
  4. Preview the sizes and copy the CSS variables.


About this type scale generator
A modular type scale multiplies a base size by the same ratio for each step, creating a natural rhythm between body text, subheadings and headings. Ratios are borrowed from music intervals: the major third (1.25) is a versatile default, while the golden ratio (1.618) creates dramatic, high-contrast headlines.
Output in rem keeps your typography accessible because it scales with the user’s browser font settings.

Frequently asked questions
What is the best type scale ratio?
For apps and dashboards use 1.125–1.2. For marketing sites and blogs, 1.25–1.333 works well. Use 1.5+ for bold, editorial headlines.
Why use rem for font sizes?
rem units respect user font-size preferences, which is better for accessibility than fixed pixels.
