How to use the Neumorphism Generator
  1. Pick a base color; the page background uses the same color.
  2. Choose flat, concave, convex or pressed.

  4. Copy the CSS.


About this neumorphism generator
Neumorphism (“new skeuomorphism”) became popular around 2020. Each element uses the same color as its background and two shadows: a dark one offset away from an imagined light source in the top-left and a light one offset toward it. The pressed variant uses inset shadows to look pushed in.
The style has a well-known weakness: low contrast. Elements are separated from the background only by soft shadows, which many users with low vision can’t see.


Worked example
On a #e8e2d8 background, a 16px offset, 32px blur and 15% intensity gives a gentle raised card. Add a colored icon or border so buttons stay recognisable.


Tips and best practices
  • Use neumorphism for decorative surfaces and large controls, not for small text buttons.
  • Add a visible label, icon or border to interactive elements so they don’t rely on shadows alone.
  • Mid-tone backgrounds work best: on pure white the light shadow disappears.
  • Use the pressed style for the active state of toggles and segmented controls.
  • Keep intensity moderate (10–20%) for a subtle, premium look.

Frequently asked questions
Is neumorphism accessible?
Not by default. Soft shadows give low contrast, so add clear labels, borders or color changes for interactive states.
What background works best for neumorphism?
A light-to-mid tone that is neither pure white nor black, so both the light and the dark shadow are visible.
