About this custom scrollbar generator
There are two ways to style scrollbars. The standard properties scrollbar-color and scrollbar-width work in Firefox and in Chrome/Edge 121+. The older ::-webkit-scrollbar pseudo-elements give more control (radius, hover, padding) and work in Chrome, Edge and Safari.
In Chromium, setting the standard properties disables the WebKit pseudo-elements. The generated code therefore wraps the standard properties in @supports not selector(::-webkit-scrollbar), so Firefox gets the standard version and WebKit/Blink browsers keep the detailed styling.


Tips and best practices
  • Keep the thumb clearly visible against the track; a 3:1 contrast ratio is a sensible minimum.
  • Don’t make scrollbars thinner than about 8px on desktop; thin bars are hard to grab with a mouse.
  • Style scrollbars on inner scroll areas (sidebars, code blocks) rather than the whole page if you want to stay subtle.
  • Mobile browsers use overlay scrollbars and mostly ignore these styles; that’s normal.
  • Use the “thumb padding” option to create a floating thumb effect with a border in the track color.

Frequently asked questions
Can I style scrollbars in Firefox?
Partly. Firefox supports scrollbar-color and scrollbar-width, but not radius or hover styles.
Why does my ::-webkit-scrollbar CSS not work in Chrome?
Since Chrome 121, setting scrollbar-color or scrollbar-width on the same element disables the ::-webkit-scrollbar styles. Use the @supports pattern in the generated code.
