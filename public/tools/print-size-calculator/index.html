How to use the Print Size & DPI Calculator

  1. Enter your image’s pixel dimensions and choose a print DPI to see the print size.
  2. Or pick a paper size such as A4 or 8×10 to see the pixels required.
  3. Use 300 DPI for professional prints and 150 DPI for large posters viewed from a distance.
  4. Add bleed if your design runs to the edge of the paper.

About this print size & dpi calculator

Print resolution is measured in dots per inch (DPI). To print sharply at a given size, multiply the size in inches by the DPI: an A4 page (8.27 × 11.69 in) at 300 DPI needs about 2480 × 3508 pixels. Large posters are viewed from further away, so 150 DPI is usually enough.

Changing the DPI value in a file’s metadata doesn’t add detail — only the pixel dimensions matter for print quality.

Frequently asked questions

How many pixels do I need for an A4 print?

At 300 DPI an A4 print needs 2480 × 3508 pixels. At 150 DPI it needs 1240 × 1754.

Is 72 DPI good for printing?

No. 72 DPI is a screen convention. For print, aim for 300 DPI for close viewing and at least 150 DPI for posters.
