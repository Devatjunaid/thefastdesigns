About this qr code generator

A QR (Quick Response) code stores data in a grid of square modules. It was invented in 1994 by Denso Wave for tracking car parts and is now an ISO standard (ISO/IEC 18004). This generator creates static codes: your URL or text is encoded directly into the pattern. There is no tracking redirect, no account and nothing that can expire.

Error correction uses Reed–Solomon codes. Higher levels let the code survive damage or a logo overlay, but add more modules. Level M (about 15% recovery) is a good default for screens and print.

Worked example

https://thefastdesigns.online at error correction M fits in a version 3 code (29 × 29 modules). For print scanned at arm’s length, make it at least 2 cm wide.

Tips and best practices

  • Keep at least a 4-module quiet zone (white margin) around the code; the downloads include it.
  • For print, the code should be roughly 2 cm (0.8 in) wide at minimum; increase size for long scanning distances (about 1/10 of the distance).
  • Shorter URLs give simpler codes that scan faster; use a short, clean link where possible.
  • Use error correction H if you plan to place a small logo in the middle.
  • Always test the final printed or exported code with two different phones before publishing.

Frequently asked questions

Do these QR codes expire?

No. They are static codes that contain your data directly, so they work as long as the destination (for example your website) exists.

Can I change the URL after printing?

Not with a static code. Changing the destination later requires a dynamic QR service that uses a redirect link.

Which format should I use for print?

SVG. It is vector, so it stays sharp at any size.
