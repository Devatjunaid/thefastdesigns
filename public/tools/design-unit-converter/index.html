About this design unit converter

Designers move between print and screen constantly. Print uses absolute units — points, picas, inches and millimetres — while screens use pixels and relative units like em and rem. The link between them is resolution: CSS defines 1 inch as 96 pixels, and typography defines 1 inch as 72 points.

So 12pt type equals 16px in CSS, and a 10mm margin equals about 37.8px on screen or 118px at 300 DPI.

Worked example

At the CSS standard of 96 DPI, 12pt equals 16px and 10mm is about 37.8px. At 300 DPI, the same 10mm is about 118 pixels.

Tips and best practices

  • When a print designer says “12pt”, the web equivalent is 16px at the CSS standard 96 DPI.
  • Points and picas come from traditional typesetting: 12 points make 1 pica and 6 picas make 1 inch.
  • Use mm for print layouts in Europe and inches in North America to avoid rounding errors.
  • em units compound when nested, so prefer rem unless you want sizes relative to a parent.
  • Pixel values for print depend entirely on DPI; always confirm the target DPI first.
