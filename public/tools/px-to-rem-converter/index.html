About this px to rem converter

The rem unit is relative to the root (html) font size. Using rem for typography and spacing means your entire layout scales when a user increases their browser’s default font size — an important accessibility win over fixed pixels.

With the default 16px root: 8px = 0.5rem, 12px = 0.75rem, 24px = 1.5rem and 32px = 2rem.

Worked example

With the default 16px root, 24px is 1.5rem and 14px is 0.875rem. If your root font size is 18px, the same 24px becomes 1.3333rem.

Tips and best practices

  • Use rem for font sizes, spacing and breakpoints in media queries; use px for borders and hairlines.
  • Avoid setting html { font-size: 62.5% }; it breaks the user’s expectations and complicates third-party components.
  • Write values with four decimals at most; browsers round to fractions of a pixel anyway.
  • Media queries in em or rem respond to browser zoom and text settings more consistently.
  • Keep a cheat sheet of your most common values (8, 12, 16, 24, 32px) in your design tokens.

Frequently asked questions

How many pixels is 1rem?

1rem equals the root font size, which is 16px by default in all major browsers.

What is the difference between rem and em?

rem is relative to the root element; em is relative to the font size of the current element’s parent, so em values compound when nested.
