About this px to rem converter

The rem unit is relative to the root (html) font size. Using rem for typography and spacing means your entire layout scales when a user increases their browser’s default font size — an important accessibility win over fixed pixels.

With the default 16px root: 8px = 0.5rem, 12px = 0.75rem, 24px = 1.5rem and 32px = 2rem.

Frequently asked questions

How many pixels is 1rem?

1rem equals the root font size, which is 16px by default in all major browsers.

What is the difference between rem and em?

rem is relative to the root element; em is relative to the font size of the current element’s parent, so em values compound when nested.
