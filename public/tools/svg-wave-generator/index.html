SVG Wave Generator

Break up long pages with flowing wave dividers. Stack several layers for depth and flip them to sit at the top or bottom of a section.

100% freeNo sign-upWorks offlinePrivate — runs in your browser


How to use the SVG Wave Generator
  1. Choose the number of layers and waves.
  2. Adjust the height and pick a color.
  3. Set whether the wave sits at the top or bottom of a section.
  4. Randomize until you like it, then download or copy the SVG.


About this svg wave generator
Wave dividers soften the transition between page sections and add movement to static layouts. Using several semi-transparent layers of the same color creates a sense of depth without extra colors.
The SVG uses preserveAspectRatio="none" so it stretches to any width — place it at the edge of a section with display: block; width: 100%.

Frequently asked questions
How do I add an SVG wave to my website?
Paste the SVG code at the top or bottom of your section and give it width: 100% and display: block. Match the color to the next section’s background.
Will the wave look good on mobile?
Yes, it stretches to fit any screen width. Adjust the height with CSS for smaller screens if needed.
