How to use the Image to Base64 Converter
  1. Choose “Image → Base64” and upload an image.
  2. Copy the data URI, the HTML img tag or the CSS background code.
  3. To reverse it, switch to “Base64 → Image” and paste your string.
  4. Click Decode to preview and download the image.


About this image to base64 converter
A Base64 data URI embeds an image directly inside your code, saving an extra HTTP request. It’s perfect for tiny icons, email templates and single-file HTML documents. Keep in mind Base64 is about 33% larger than the original binary, so it’s best for small images under ~10 KB.


Worked example
A 750-byte PNG icon becomes about 1,000 characters of Base64, roughly 33% larger. That is fine for a tiny icon used once, but a 100 KB photo would add about 133 KB to your HTML or CSS.


Tips and best practices
  • Base64 adds about 33% to the size, so only inline images under roughly 5–10 KB.
  • Inlined images can’t be cached separately; if the same image appears on many pages, use a normal file.
  • For SVG, a URL-encoded data URI (not Base64) is usually smaller.
  • Many email clients block or strip data URI images; test before using them in newsletters.
  • Don’t inline images that change often; every change invalidates the whole CSS or HTML file.

Frequently asked questions
When should I use Base64 images?
For very small images like icons, placeholders and email assets where avoiding an extra request matters more than file size.
Can I decode Base64 without the data: prefix?
Yes. The decoder detects common image signatures (PNG, JPG, GIF, WebP, SVG) automatically.
