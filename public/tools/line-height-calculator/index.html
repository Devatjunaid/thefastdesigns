Good typography is invisible. When line height, line length and font size work together, readers stop noticing the text and start absorbing the ideas. Too little space and lines blur together; too much and the eye loses its place when jumping to the next line. Most body text reads best with a line height between 1.4 and 1.6 times the font size.



How to use the Line Height Calculator
  1. Enter your font size.
  2. Set the line height ratio, or click “Suggest ratio”.
  3. Set the line length in characters and optional grid snapping.
  4. Check the preview and copy the CSS.


About this line height calculator
Line height (leading) is the vertical distance between lines of text. For body text, 1.4–1.6 is the widely recommended range, and WCAG success criterion 1.4.12 (Text Spacing) requires that content still works when users increase line height to at least 1.5. Headings need less, around 1.1–1.3, because large type already has generous space between lines.
Line length matters too: longer lines need more line height so the eye can find the start of the next line. Readable body text usually sits between 45 and 75 characters per line.


Tips and best practices
  • Write line-height without a unit (1.5, not 1.5em) so child elements inherit the ratio, not a fixed size.
  • Decrease the ratio as font size increases: body 1.5, subheads 1.3, large headings 1.1–1.2.
  • Snap line heights to a 4px grid to keep vertical rhythm consistent with your spacing scale.
  • Use the ch unit for max-width to control line length directly in characters.
  • Fonts with a tall x-height usually need a bit more line height than fonts with a small x-height.

Frequently asked questions
What is the best line height for body text?
Around 1.5 times the font size is a reliable default and matches the WCAG text spacing guideline.
Should line-height have units?
Usually no. A unitless value scales with each element’s own font size and avoids inheritance problems.
