About this css clip-path generator
clip-path: polygon() hides everything outside a shape defined by percentage coordinates, measured from the top-left corner of the element. Because the points are percentages, the shape scales with the element. Unlike rotated borders or masks, clip-path doesn’t change layout, and it can be animated between polygons that have the same number of points.


Worked example
polygon(0 0, 100% 0, 100% 85%, 0 100%) slants the bottom edge of a hero section, a sharper alternative to a wave divider.


Tips and best practices
  • Box shadows and outlines are clipped too; use filter: drop-shadow() on a parent wrapper if you need a shadow.
  • Clipped areas don’t receive clicks, which is useful for irregular buttons.
  • To animate between two shapes, both polygons must have the same number of points.
  • The “slanted section” preset is a neat way to angle the bottom edge of a hero section.
  • Keep important image content in the middle so the shape doesn’t crop faces or text.

Frequently asked questions
Is clip-path supported in all browsers?
Yes, clip-path with basic shapes like polygon() works in all modern browsers without prefixes.
Can I add a border to a clip-path shape?
Not directly. A common trick is to clip a slightly larger parent element in the border color and an inner element in the fill color.
