How to use the CSS Grid Generator
  1. Set the number of columns and rows.
  2. Adjust column and row gaps with the sliders.
  3. Optionally type custom track sizes like “200px 1fr 2fr”.
  4. Copy the CSS and HTML into your project.


About this css grid generator
CSS Grid is the most powerful layout system on the web, letting you control rows and columns at the same time. The fr unit divides free space proportionally, minmax() sets flexible limits, and repeat(auto-fit, minmax(200px, 1fr)) creates a responsive grid that wraps automatically without media queries.


Worked example
Tick the responsive option to get repeat(auto-fit, minmax(200px, 1fr)). In a 1200px container with 16px gaps that gives five columns; on a phone it gives one, without a single media query.


Tips and best practices
  • repeat(auto-fit, minmax(240px, 1fr)) builds a responsive card grid without a single media query.
  • Use grid-template-areas for page layouts; named areas make the structure readable in the CSS.
  • gap replaces margins between grid items and never adds space on the outer edges.
  • Use minmax(0, 1fr) instead of 1fr when long words or code blocks force columns to overflow.
  • Subgrid (grid-template-columns: subgrid) lets nested items align to the parent grid in all modern browsers.

Frequently asked questions
What is the difference between CSS Grid and Flexbox?
Grid is two-dimensional (rows and columns together) while Flexbox is one-dimensional (a single row or column). Use Grid for page layouts and Flexbox for components.
What does 1fr mean?
One fraction of the remaining free space in the grid container.
