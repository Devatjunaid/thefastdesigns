How to use the Image Color Picker

  1. Upload, drag & drop or paste an image.
  2. Move your cursor over the image to preview colors live.
  3. Click to pick a color — the HEX code is copied automatically.
  4. Use the HEX or RGB buttons to copy saved colors again.

About this image color picker

An image color picker (or eyedropper) is the fastest way to match colors from a client’s logo, a mood-board photo or a competitor’s website screenshot. Because the image is drawn onto a canvas inside your browser, you get the exact pixel value without uploading files to a server.

Large images are scaled to a maximum of 2000px for smooth performance; this doesn’t change solid colors in logos or UI screenshots.

Tips and best practices

  • Zoomed or compressed screenshots blend colors at edges; click the middle of a flat area for the true color.
  • JPEG compression shifts colors slightly, so sample from PNG screenshots when matching a brand color exactly.
  • Hold your cursor over gradients to watch values change and find the start and end colors.
  • Sample several points in a photo’s shadows, midtones and highlights to build a natural palette by hand.
  • Colors in images can carry an embedded color profile; your browser converts them to sRGB, which is what web pages use anyway.
