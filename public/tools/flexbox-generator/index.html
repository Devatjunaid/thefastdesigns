How to use the Flexbox Generator
  1. Pick a flex-direction to lay items in a row or column.
  2. Use justify-content to distribute items along the main axis.
  3. Use align-items to align them on the cross axis.
  4. Adjust wrap, gap and item count, then copy the CSS.


About this flexbox generator
Flexbox is ideal for navigation bars, button groups, cards and centring content. justify-content works along the main axis (horizontal for rows), while align-items works along the cross axis. Switching to a column direction swaps these axes — the playground makes that behaviour easy to see.
The gap property is now supported for flexbox in all modern browsers, replacing margin hacks.


Worked example
To center content in both directions, set justify-content and align-items to center. Then switch flex-direction to column and notice that justify-content now moves items vertically, because the main axis has turned.


Tips and best practices
  • Use margin-left: auto on one flex item to push it (and everything after it) to the far end, perfect for nav bars.
  • flex: 1 makes items share space equally; flex: 1 1 0 ignores their content size entirely.
  • Add min-width: 0 to flex items containing long text so they can shrink instead of overflowing.
  • Use flex-wrap with gap for tag lists and button groups that should wrap onto new lines.
  • If you need items to align in two directions at once, switch to CSS Grid.

Frequently asked questions
How do I center a div with flexbox?
Set display: flex; justify-content: center; align-items: center on the parent element.
When does align-content apply?
Only when items wrap onto multiple lines. It controls the spacing between those lines.
