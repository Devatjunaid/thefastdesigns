About this fluid typography clamp generator
The CSS clamp(min, preferred, max) function lets a value grow with the viewport while staying within limits. Combining a rem value with a vw value in the middle keeps text accessible: it still responds to the user’s browser zoom and font settings.
The formula is linear interpolation: slope = (maxSize − minSize) / (maxViewport − minViewport). Fluid sizing works for font sizes, padding, margins and gaps alike.


Tips and best practices
  • Test fluid type at 200% browser zoom; WCAG requires text to remain resizable, and pure vw sizes don’t scale with zoom.
  • Keep the maximum font size at no more than about 2.5 times the minimum for the zoom test to pass reliably.
  • Use the same min and max viewport for every fluid value so sizes scale in sync.
  • Fluid spacing (padding and gaps) pairs nicely with fluid type for consistent proportions.
  • Headings benefit most from fluid sizing; body text usually only needs a small range like 16–18px.

Frequently asked questions
Why use rem instead of px in clamp()?
rem respects the user’s default font size, which improves accessibility. The tool converts using your root font size.
Is clamp() supported by all browsers?
Yes, clamp() is supported in all modern browsers since 2020.
