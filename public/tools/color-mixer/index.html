Steps from A to B

How to use the Color Mixer

  1. Pick the first and second colors.
  2. Drag the mix slider to set how much of color B to blend in.
  3. Copy the mixed color in HEX, RGB or HSL.
  4. Use the step swatches for gradients or chart scales.

About this color mixer

Mixing colors digitally is useful for finding the midpoint between brand colors, creating hover states that lean towards a background, or building sequential color scales for charts and heat maps.

The mixer interpolates each RGB channel linearly — the same method used by CSS color-mix(in srgb, …) and Sass mix().

Frequently asked questions

How do I find the color halfway between two colors?

Set the mix slider to 50% and the result shows the exact midpoint color.

Is this the same as mixing paint?

No. Digital mixing is additive light (RGB), while paint mixing is subtractive, so blue + yellow won’t give green here.
