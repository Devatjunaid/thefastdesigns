About this cubic bezier generator
Easing makes motion feel natural. The horizontal axis is time and the vertical axis is progress. A steep start means a fast beginning; a curve that rises above the top creates an overshoot or “bounce back” effect.
As a rule of thumb, use ease-out for elements entering the screen, ease-in for elements leaving, and ease-in-out for elements moving across the screen. Keep UI transitions between 150ms and 400ms.


Worked example
cubic-bezier(0.16, 1, 0.3, 1) (ease-out-expo) starts fast and settles gently, which suits dropdowns and modals appearing on screen. Pair it with a duration of 200–300ms.


Tips and best practices
  • Keep most UI transitions between 150ms and 300ms; larger elements and distances can go up to 500ms.
  • Use ease-out for elements appearing, so they arrive quickly and settle gently.
  • Overshoot (“back”) curves add playfulness but get tiring if used on every interaction.
  • Exit animations should be slightly faster than enter animations.
  • Wrap motion in @media (prefers-reduced-motion: reduce) and shorten or remove it for users who ask for less motion.

Frequently asked questions
What does cubic-bezier mean in CSS?
It defines a timing curve with two control points (x1, y1) and (x2, y2). The x values must be between 0 and 1; y values can go beyond to create overshoot.
What is the default CSS easing?
The default is “ease”, which equals cubic-bezier(0.25, 0.1, 0.25, 1).
