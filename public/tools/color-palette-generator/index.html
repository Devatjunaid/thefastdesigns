Color Palette Generator

Pick a base color and a color harmony rule to generate a balanced five-color palette. Hit “Random” or press the space bar for fresh inspiration.

How to use the Color Palette Generator
  1. Choose a base color with the picker or type a HEX value.
  2. Select a color harmony such as analogous, complementary or triadic.
  3. Review the five generated swatches — click any swatch to copy its HEX code.
  4. Copy the ready-made CSS custom properties into your stylesheet.


About this color palette generator
Color harmonies are proven combinations based on positions on the color wheel. Analogous palettes use neighbouring hues for calm, cohesive designs. Complementary palettes pair opposite hues for strong contrast, while triadic and tetradic schemes spread hues evenly for vibrant, balanced layouts.
Use the monochromatic option for minimal brand systems and the neutral + accent option to get a practical UI palette with dark text, light backgrounds and one highlight color.

Frequently asked questions
What is a complementary color palette?
It combines a color with the hue directly opposite on the color wheel (180° apart). The result is high contrast and works well for call-to-action buttons.
Can I use these palettes commercially?
Yes. Colors cannot be copyrighted and every palette you generate is yours to use for free.
How do I export a palette?
Click “Copy CSS” to copy CSS variables, or click individual swatches to copy single HEX codes.
