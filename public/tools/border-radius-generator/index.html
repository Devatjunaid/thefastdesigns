About this border radius generator
The CSS border-radius property rounds the corners of any element. The shorthand order is top-left, top-right, bottom-right, bottom-left. Pixel values give consistent corners across sizes; percentage values scale with the element, which makes perfect circles (50%) and ellipses easy.
Consistent corner radii are a hallmark of polished UI — pick one or two radius values and reuse them across buttons, cards and inputs.


Tips and best practices
  • Nested rounded elements look best when the inner radius equals the outer radius minus the padding.
  • Keep a small set of radii, for example 4px for inputs, 8px for buttons and 16px for cards.
  • Fully rounded “pill” buttons feel friendly and casual; small radii feel more formal and technical.
  • Use the eight-value syntax (with a slash) to create organic blob shapes: border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%.
  • overflow: hidden on a rounded container clips images inside it to the same corners.

Frequently asked questions
How do I make a circle with CSS?
Give the element equal width and height and set border-radius: 50%.
How do I make a pill-shaped button?
Use a very large pixel radius such as 999px — the browser caps it at half the element height.
